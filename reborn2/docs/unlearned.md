# What I Unlearned — reborn2

1. I stopped treating automation as the final answer. The project keeps every draft in a human-review state; no message is sent without approval.
2. I stopped trusting one keyword as sufficient evidence. The model needs a clearer rule set, confidence thresholds, and fallbacks, otherwise ambiguous messages get misclassified.
3. I stopped keeping state only in memory. Real workflows need durable session state and history so the review workspace can survive refreshes and restarts.
4. I stopped equating “fast prototype” with “finished product.” The real submission needed a backend, API layer, test coverage, a UI, and honest logs about what broke.
5. I stopped separating the project from its context. This folder is the real Quest submission; re_born is only the prototype and reference path, not the final artifact.

The main unlearning was not about giving up tools; it was about giving up the habit of pretending the first version was final.
